# 角色等級移除與職業精通技能樹：交付報告（v0.167）

開工前稽核與替代機制的決定見 `docs/level-removal-audit.md`。本報告依規格第十五節逐項說明。

## 1. 實際移除的角色等級系統及程式位置

| 項目 | 原位置 | 處理 |
|---|---|---|
| 角色等級／經驗欄位 `lv`、`xp`、`xpFraction` | 角色資料、存檔 | 刪除；舊存檔在 `js/core/save-validation.js` 轉成相容資料後刪除 |
| 經驗發放 `awardXP`、升級需求 `need`、等級上限 `levelCap` | `js/core/core-game.js` | 刪除 |
| 等級屬性成長 `growthPerLevel`、`growthSteps`、速度吃等級 | `js/balance/progression-model.js`、`core-game.js` | 刪除，屬性只用職業固定值 |
| 經驗曲線與遷移 | `js/balance/progression-runtime.js` | 刪除 |
| 擊殺、離線、收益券、每日委託、許願湖、終局地圖的經驗 | `core-game.js`、`js/combat/offline-exploration.js`、`js/world/region-vouchers.js`、`js/world/daily-commissions.js` 等 | 刪除；舊收益券的經驗附件領取後無效果 |
| 等級差規則：經驗懲罰、掉落衰減、怪物對高等級差增傷 | `core-game.js`、`balanceSettings.progression.xpLevelGap`、`drops.levelGap` | 刪除 |
| 地圖進入條件（等級 +5） | `canVisit` | 改為擊敗前一張地圖首領 |
| 裝備穿戴等級限制 | `gearRequiredLevel` 相關檢查 | 取消限制，裝等只作為強度與推薦參考 |
| 升級卷軸 | 商店、背包、`core-game.js` | 停用；舊存量依賣價換成金幣 |
| 每級能力點 `progression.levelRewards` | 隊伍模型、精通設定 | 刪除 |
| 介面上的 LV 顯示 | 角色資訊、成員標籤、戰鬥卡片、側欄遠征目標、存檔卡、招募視窗 | 改為「職業精通 Lv」、「裝等」或「推薦裝等」 |

保留不動：怪物等級（作為怪物強度階級）、裝備等級、生活技能、技能寶石、精煉等級、武器／元素精通。

## 2. 新的角色屬性計算與成長來源

角色屬性 = 職業固定基礎值（`classes[].initialStats`）＋ 裝備 ＋ 職業精通加成 ＋ 二轉倍率與其他既有效果。

- 依決定採「固定基礎值」，裝等不額外賦予角色能力。
- 職業精通加成在 `js/equipment/equipment-identity.js` 的 `stats()` 加進職業基礎值，再套用百分比效果，所以夥伴的百分比被動也會放大這部分。
- 成長來源：裝備（主要）、職業精通加成、二轉倍率。

| 職業 | 基礎 HP／攻／防 |
|---|---|
| 戰士 | 30／10／6 |
| 法師 | 22／12／3 |
| 弓箭手 | 25／11／4 |
| 牧師 | 27／10／5 |

戰力變化（同職業穿同階 4 件裝備、品質 1）見稽核文件第六節：後期攻擊約為改版前的 40–50%、生命約 50–60%。

## 3. 職業精通等級、經驗曲線與屬性獎勵

- 資料：主角是 `buildSystem.permanent.classes[職業].xp`（每個職業各自累積，切換職業保留）；夥伴是 `companionMastery.xp`。
- 經驗來源：施放技能 +2、普攻 +1（`skills.mastery.skillUseXp`、`basicAttackXp`），受限時「精通經驗」加成影響。武器／元素精通照舊累積，職業精通跟著每次獲得一起成長。
- 曲線：第 L 級升級需要 `8 + 5L + L²`（`xpBase`、`xpLinear`、`xpQuadratic`），上限 Lv30（`maxLevel`），滿級共 10,970 點；達上限後不再累積。
- 屬性加成（每級，`skills.mastery.classBonus`，只算目前職業）：

| 職業 | 每級加成 | Lv30 合計 |
|---|---|---|
| 戰士 | 生命 +3、防禦 +0.5 | 生命 +90、防禦 +15 |
| 法師 | 生命 +1、攻擊 +0.6 | 生命 +30、攻擊 +18 |
| 弓箭手 | 生命 +1、攻擊 +0.5、暴擊 +0.1% | 生命 +30、攻擊 +15、暴擊 +3% |
| 牧師 | 生命 +2、攻擊 +0.3、防禦 +0.2 | 生命 +60、攻擊 +9、防禦 +6 |

- 二轉：職業精通達 Lv15（`progression.advance.masteryLevel`），並保留原有的「任一主要武器／元素精通 Lv4」與金幣、礦石、材料消耗。

## 4. 各職業技能樹與解鎖條件

規則：

- 技能樹就是 `skillSystem.classRules[職業]` 的 `initial`（初始職業）與 `advanced`（二轉後）節點。
- 達到需求精通（與前置節點、二轉後節點則要求已二轉）就自動解鎖，不消耗點數。
- 解鎖不等於裝備：主動、觸發、輔助技能仍要放進技能槽；被動技能可在被動頁停用。
- 原角色等級門檻 L 換算為職業精通 L−1（`skillSystem.masteryGateVersion=1`）。
- 目前資料沒有設定前置節點（`prerequisites`）與手動座標（`position`），平衡器的技能樹分頁可以加入。

技能頁的技能槽下方顯示技能樹：

- 節點標示需求精通。
- 使用中、已解鎖、未解鎖以框線區分。
- 二轉節點以分隔線標出。
- 點選節點會列出條件、前置與裝備狀態。

| 職業 | 精通 Lv0 | 精通 Lv2 | 精通 Lv4 | 二轉後 Lv14 | 二轉後 Lv19 |
|---|---|---|---|---|---|
| 戰士 | 嘲諷（主動） | 減傷（主動）、順勢斬（被動） | 重擊（主動） | 聖鋼裁決（主動）、破甲怒吼（輔助） | 不屈戰意（觸發） |
| 法師 | 魔爆（主動） | 變形（主動）、魔力循環（被動） | 火球（主動） | 隕星墜落（主動）、元素灼印（輔助） | 魔力迴響（觸發） |
| 弓箭手 | 連射（主動） | 狙擊（主動）、箭雨（主動） | 繩索陷阱（主動） | 疾風箭雨（主動）、風行庇佑（輔助） | 生命之箭（觸發） |
| 牧師 | 聖光（主動） | 治療（主動）、神聖光牢（主動） | 癒合（主動） | 黎明聖印（主動）、光明祈願（輔助）、苦痛蔓延（輔助） | 神聖庇護（觸發） |

二轉後 Lv14 的節點實際要到二轉（精通 Lv15）後才會開放。

## 5. 既有技能取得來源的處理

| 來源（技能定義數） | 處理 |
|---|---|
| 職業 `class`（16）、二轉 `advanced`（13） | 由技能樹節點決定，門檻改為職業精通 |
| 夥伴 `companion`（124） | 看夥伴自己的精通；夥伴技能、被動、二轉的等級門檻同樣換算為精通 |
| 任務 `quest`（8） | 不變，完成任務取得；有精通需求者照精通判定 |
| 裝備 `equipment`（24） | 不變，穿戴對應裝備時可用 |
| 成就解鎖條件（擊敗首領、菁英、持有首領裝備） | 不變，與精通條件一起判定 |
| 劇情與教學的「主角等級」條件 | 改為「主角職業精通等級」（L→L−1） |
| 支線與每日委託的等級範圍、等級目標、經驗獎勵 | 刪除 |

## 6. 平衡器修改項目與資料格式變動

平衡器（`DreamingAbyss-BalanceEditor`，分支 `feature/level-removal`）：

- 移除：經驗曲線編輯器、職業每級成長、等級差懲罰、掉落等級差、等級上限、任務等級範圍與經驗、越級收益券金幣、每級能力點。
- 新增：
  - 二轉需求精通等級（`progression.advance.masteryLevel`）、裝等上限（`equipment.maxLevel`）。
  - 各職業精通屬性加成（`skills.mastery.classBonus`）、地圖推薦裝等（`maps.catalog[].recommendedGearLevel`）。
  - 「職業精通預覽」表。
- 技能樹分頁：
  - 依職業排列節點，可設定需求精通、前置節點與位置，並即時預覽。
  - 會檢查：循環、無效 ID、跨職業前置、初始節點以二轉節點為前置、永遠無法解鎖的節點。前五項會擋下發布。
  - 職業技能不在技能樹中時只顯示提醒，不擋發布。
- 模擬試算：「升級速度」改為「精通速度」；技能試打以精通上限解鎖技能；裝備比較不再調整等級。
- 同步流程：`scripts/sync-game.cjs` 加入技能系統與共用模型（任務、夥伴被動、背包圖示）的同步；技能系統區塊改為原地替換。
- 欄位追蹤矩陣與數值邊界報表已依新資料重建。

資料格式：

- 已發布資料（`data/balance` 模組，dataRevision 18）已遷移，詳見 `DEVELOPMENT.md` v0.161 一節。
- `classRules` 節點由 `{skillId, level}` 改為 `{skillId, masteryLevel, prerequisites?, position?}`。
- 舊格式文件匯入時由 `migrateMasteryGates` 自動換算一次。

## 7. 舊存檔遷移規則與測試結果

規則：

1. 舊等級轉成 `mapAccess`（舊等級可進入的地圖維持開放）與 `party.legacySkillLevel`。
2. 舊等級已解鎖的技能維持可用：需求精通 L 在 `legacySkillLevel ≥ L+1` 時視為達成。
3. 等級與經驗刪除，不換算成精通。
4. 升級卷軸依賣價換成金幣。
5. 已裝備的技能、裝備、背包、隊伍不變。
6. 重複載入不重複發放：等級已刪、卷軸已歸零、相容等級只寫一次。

測試：

- `tests/level-removal.test.cjs`「an old save keeps its maps, skills and gear」：使用真實的 LV16 舊存檔，驗證地圖、技能門檻、卷軸退款，以及重新載入不重複發放。
- `tests/legacy-progression.browser.test.cjs`：在瀏覽器載入 v1 存檔，驗證載入兩次結果相同。
- `tests/team-save-compatibility*.test.cjs`：隊伍存檔相容。
- 結果見第 8 節。

## 10. 尚未完成的項目與已知風險

1. **後期戰力下降**：固定基礎值後，攻擊約為改版前 40–50%，覺醒地區（31–60）會明顯變難。依決定先不改裝備與怪物，需以實際遊玩確認後再調整裝備基底數值或怪物強度。
2. **職業精通成長偏快**：新角色在第一張地圖約 1 小時到 Lv12、3 小時到 Lv19，二轉（Lv15）約 1.5 小時可達。精通曲線沿用原武器精通曲線，建議驗收時評估是否在平衡器調高 `xpBase`／`xpLinear`／`xpQuadratic`。
3. **技能樹結構**：目前資料沒有設定前置節點，各職業的樹由精通門檻決定。平衡器已可設定前置與位置，內容設計尚待補上。
4. **二轉條件重疊**：二轉仍保留「任一主要武器／元素精通 Lv4」。職業精通 Lv15 時這條件幾乎一定已滿足，可在後續版本移除。
5. **怪物等級顯示**：怪物與地圖仍顯示 LV（怪物強度階級），與玩家精通等級意義不同，可能需要另外說明。
6. **舊存檔相容欄位**：`party.legacySkillLevel` 會永久保留在舊存檔裡，以維持舊技能可用。
7. **未合併與未部署**：兩個 repo 都只在 `feature/level-removal`，等驗收後才合併到 `chatgpt-dev` 並部署。
