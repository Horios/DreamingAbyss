# Emberwild BUG 分類、修復與驗收計畫

建立日期：2026-11-01。單一工作清單：[Issue #5](https://github.com/Horios/Emberwild/issues/5)。工作分支 `chatgpt-dev`，正式分支 `main` 不修改。本文記錄當前流程，歷史追蹤與逐筆驗收以 Issue 為準。

## 1. BUG 收集與證據

每筆錯誤記錄「編號／優先級／出現版本及 SHA／系統／操作路徑／預期與實際／重現條件／錯誤 logs 或畫面／可能影響的存檔／根因／修正 commit／測試證據／發布狀態」。僅憑異常畫面不能判斷根因；`skipped`、`cancelled` 與未完成均不計入成功。

- **P0：** 無法進入遊戲、存檔毀損或有效備份遭覆寫、獎勵重領或資源消失、持續性進度損失。應先停止部署並復原／保留原始 JSON。
- **P1：** 戰鬥、離線結算、裝備、任務與商店無法按規則完成；資料或裝備容量限制失效；必要 CI 紅燈。
- **P2：** 個別功能顯示、手機捲動、操作提示、視覺特效與排序異常。
- **TEST／INFRA：** 測試舊前提、瀏覽器 fixture 重置、CI 執行逾時、私有平衡器跨 repo fixture 不足，須與真正遊戲 BUG 分離。

## 2. 統一驗收矩陣

| 模組 | 必測流程 | 不可接受的結果 |
| --- | --- | --- |
| 存檔／版本 | 新舊 JSON；正常重載；損壞主檔＋正常備份；雙損壞拒絕；儲存空間不足；多分頁所有權；版本號遞增與部署 commit | 遺失可用備份、無法讀舊檔、只修改介面卻沒寫入 |
| 離線掛機 | 1／3／8／11／24 小時；一般／菁英／BOSS；升級界限、經驗衰減；加倍券過期、藥水消耗、掉落與背包滿；中斷恢復及收益不重領 | 不合理跨級經驗、重複收益、容量超限或計算失敗後殘留半筆交易 |
| 戰鬥與技能 | 四職業、夥伴、被動與主動裝備；多目標擊殺鏈；冷卻、控制、護盾與增減益；前景／離線一致性 | 行動與動畫錯置、無效技能取得、離線與線上不符 |
| 裝備與經濟 | 裝備取得／穿戴／鎖定／強化／洗鍊／寶石／詞綴／信物；店鋪與煉金回滾；保留舊存檔所有權 | 裝備 ID 遺失、滿包仍加入、購買失敗卻扣款 |
| 世界任務／夥伴 | 任務進度／地圖條件／NPC／郵箱／許願湖；重啟持久化及一次性獎勵 | 錯誤解鎖、重領或遺失獎勵 |
| 介面／部署 | Chromium 桌機＋手機、背包捲動、收益視窗、所有操作按鈕；正式／測試站區分與版本顯示 | 彈窗攔截後無解決流程、測試已更新而網站仍舊版 |

## 3. 同一版本驗收流程

1. 記錄待驗 SHA 與 `data/preview-version.json`，先鎖定重現用的隔離測試存檔，不拿玩家原存檔改寫。
2. 針對失敗 logs 逐項重現，歸類「正式程式、測試環境、既有預期、部署、待確認」。先修根因，不改掉落、經驗或技能平衡。
3. 每一項修正新增 deterministic fixture 與回歸斷言，包括存檔原始 bytes、前後狀態、失敗回滾、離線快速／完整模式。
4. 在同一 SHA 通過九項必要驗證（含版本遞增）及六項 Extended regression，沒有 skipped 或 cancelled。必要的跨 repo 私有編輯器測試需獨立證據。
5. GitHub Pages main-context 部署成功後，核對 `preview/data/build.json` 的 commit、畫面版本號與 `data/preview-version.json` 相同，並用真實瀏覽器重整驗證。
6. 未通過項目寫回 Issue #5，附上 run／job／commit 連結，保留 open；未驗證不得寫成已完成。
