## 共用規則與例外

- 在現有 `base.css` 定義頁面內距、區塊間距、面板內距、卡片／控制間距與主從比例。
- 桌機頁面內距 16px、主要間距 16px；手機頁面內距 12px、主要間距 12px、一般面板內距 14px。
- 沿用 `page-readability.css` 管理自然內容流，沒有新增第二份全站布局樣式檔。
- 修改原有來源規則；特別修正 `companion-tokens.css` 較晚載入的外層高度／捲動設定。沒有增加 `!important`。
- 技能槽、品質標記、裝備圖示、戰場卡片及戰報繼續使用專用尺寸與捲動規則；不強制所有卡片等高。
- 保留 CSS 載入順序；`visual-standard.css` 繼續最後載入，`paper` 的主題排除條件保持原樣。
- 所有變更 CSS 的 `index.html` 資源參數同步更新為 `20261106-v0096-layout1`。

## 驗證方法

瀏覽器尺寸：1920×1080、1366×768、1024×768、768×1024、390×844、320×568、844×390。

- 三種現有主題：ember、forest、paper。
- 20 種一般頁面／分類，在七種尺寸各量測並截圖；另檢查信箱、成就、設定、指南及許願湖彈窗。
- 人工檢視實際瀏覽器產生的桌機、平板、窄手機、背包、強化、角色、隊伍、技能與戰場截圖。
- 壓力內容：80 件裝備、展開夥伴細節、加長任務／技能名稱及額外任務卡片。
- 互動檢查：頁面切換、手機導航及更多選單、戰況、背包選取保留列表位置、穿脫裝備、鑲嵌、技能配置、篩選及主題切換。
- 既有存檔、載入、離線、動畫與遊戲規則的回歸交由相關既有測試及部署 CI 檢查，未修改其實作。

測試結果與推送、CI、部署的最終狀態分開回報；不將遠端舊版本測試或單純推送視為本版部署成功。

## 限制

- 瀏覽器自動化使用 Chromium；未在實體手機、Safari 或 Firefox 上操作。
- 使用既有新角色、測試夥伴及裝備資料，沒有取得使用者私人存檔作人工檢視。
- 有專用用途的緊湊行、戰鬥卡片和清單仍保有不同資訊密度；這些是刻意保留的例外。
- 此次 CSS 工作沒有修改遊戲 JavaScript、平衡資料、存檔格式或平衡設計器；並行導航變更另列於下方。
